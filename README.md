# Nodo de telemetría con alertas sonoras

Laboratorio N.°1 de **Desarrollo de Software VIII**, Universidad Tecnológica de Panamá, Facultad de Ingeniería de Sistemas Computacionales.
Estudiante: Juan Wilson (8-1016-1882), grupo 1GS134. Profesor: Kexy Rodríguez.

Este proyecto amplía el nodo de telemetría del Trabajo en Clase N.°3 para que la computadora avise **de oído**: cada tipo de problema tiene su propia melodía y el nodo detecta cuándo se pierde y cuándo se recupera la conexión de red. Los sonidos no congelan el sistema: mientras suena una alerta, el dashboard se sigue actualizando y el ciclo sigue detectando eventos.

Cada línea o bloque agregado o modificado lleva el comentario `# LABORATORIO`.
